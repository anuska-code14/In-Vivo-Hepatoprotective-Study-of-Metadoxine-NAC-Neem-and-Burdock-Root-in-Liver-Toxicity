# In-Vivo-Hepatoprotective-Study-of-Metadoxine-NAC-Neem-and-Burdock-Root-in-Liver-Toxicity
B.Tech thesis: dose-response and combination study of Metadoxine, NAC, Neem and Burdock Root against CCl₄-induced hepatotoxicity in Swiss albino mice. Readouts: liver ACP/ALP, serum SGPT/SGOT and bone-marrow chromosomal aberration. Includes data tables, methods and critical limitations.
